# نمونه نقشه آفلاین تهران با Leaflet

این پروژه یک نمونه خیلی ساده از استفاده‌ی Leaflet برای نمایش یک بخش کوچک از تهران است.
کاشی‌های نقشه از مسیر محلی خوانده می‌شوند و بعد از دانلود اولیه، برای نمایش همان محدوده
نیازی به اینترنت ندارید.

## محتویات پروژه

- `index.html`: صفحه اصلی نمونه
- `app.js`: تنظیمات نقشه، محدوده، زوم و مسیر نمونه
- `styles.css`: ظاهر ساده صفحه
- `tiles/tehran/{z}/{x}/{y}.png`: محل کاشی‌های آفلاین نقشه
- `tiles/missing-tile.svg`: تصویر جایگزین وقتی کاشی وجود ندارد
- `vendor/leaflet`: محل فایل‌های Leaflet بعد از دانلود
- `scripts/download-leaflet.mjs`: دانلود فایل‌های Leaflet برای اجرای آفلاین
- `scripts/download-tehran-tiles.mjs`: دانلود کاشی‌های محدوده کوچک تهران
- `docs/download-tiles.md`: راهنمای جزئی‌تر دانلود و تغییر کاشی‌ها

> این نمونه عمداً از ساختار ساده‌ی XYZ با فایل‌های PNG استفاده می‌کند. مخازنی که اشاره کردید
> روی MBTiles تمرکز دارند، اما برای یک پروژه‌ی آموزشی HTML ساده، پوشه‌ی
> `z/x/y.png` راحت‌تر اجرا می‌شود و به سرور SQLite یا پلاگین اضافه نیاز ندارد.

## اجرای سریع

اگر فایل‌های `vendor/leaflet` و `tiles/tehran` در پروژه موجود باشند:

```bash
npm run serve
```

سپس در مرورگر باز کنید:

```text
http://localhost:8080
```

اگر فایل‌های Leaflet یا کاشی‌ها را ندارید، یک بار این دستور را اجرا کنید:

```bash
npm run download:all
npm run serve
```

## رفتار نقشه

- محدوده نقشه به بخش کوچکی از مرکز تهران محدود شده است.
- زوم فقط روی سه سطح `14`, `15`, `16` فعال است.
- کاشی‌ها از مسیر زیر خوانده می‌شوند:

```text
tiles/tehran/{z}/{x}/{y}.png
```

- مسیر آبی/سبز روی نقشه یک مسیر نمونه‌ی ثابت است و به سرویس مسیریابی آنلاین وصل نیست.

## تغییر محدوده یا زوم

برای تغییر محدوده، دو فایل باید با هم هماهنگ باشند:

1. در `app.js` مقدار `mapBounds`، `center`، `minZoom` و `maxZoom` را تغییر دهید.
2. در `scripts/download-tehran-tiles.mjs` مقدار `bounds` و `zooms` را مطابق همان محدوده تغییر دهید.
3. دوباره کاشی‌ها را دانلود کنید:

```bash
FORCE_DOWNLOAD=1 npm run download:tiles
```

## تغییر مسیر نمونه

در فایل `app.js` آرایه‌ی `routePoints` را تغییر دهید. هر نقطه به شکل زیر است:

```js
[latitude, longitude]
```

مثال:

```js
[35.70064, 51.39164]
```

## دانلود کاشی‌ها از منبع دیگر

اسکریپت دانلود به‌صورت پیش‌فرض از قالب زیر استفاده می‌کند:

```text
https://tile.openstreetmap.org/{z}/{x}/{y}.png
```

برای استفاده جدی یا دانلود بیشتر، بهتر است از سرویس‌دهنده‌ی مجاز، tile server شخصی،
یا خروجی ابزارهایی مثل TileServer/TileMill/MapTiler استفاده کنید. نمونه:

```bash
TILE_URL_TEMPLATE="https://your-tile-server.example.com/{z}/{x}/{y}.png" npm run download:tiles
```

راهنمای کامل‌تر در `docs/download-tiles.md` آمده است.
